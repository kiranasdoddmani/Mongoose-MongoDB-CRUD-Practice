# Mongoose MongoDB CRUD Practice

This repository contains my practice work with **MongoDB and Mongoose**. The project focuses on understanding how Mongoose schemas, models, CRUD operations, validation, and update methods work with MongoDB.

## 📚 Topics Covered

* MongoDB connection using Mongoose
* Mongoose Schema
* Mongoose Models
* Creating documents
* `insertMany()`
* Reading documents using `find()`
* Updating documents using:

  * `findOneAndUpdate()`
  * `findByIdAndUpdate()`
* Deleting documents
* `new: true`
* `runValidators: true`
* Schema validation
* `required`
* `min`
* `max`
* `minlength`
* `maxlength`
* `enum`
* Default values
* Array fields such as `[String]`
* Basic CRUD operations

## 🔄 CRUD Operations

CRUD represents the four basic operations performed on data:

* **Create** – Add new documents
* **Read** – Retrieve documents
* **Update** – Modify existing documents
* **Delete** – Remove documents
